# Skill 与 MCP 管理使用说明

首版支持 Claude Code、Codex、Gemini CLI 的用户级资源。导航中的 **Skills** 与 **MCP** 可直接使用；管理操作由 Rust 完成。

## Skills

1. 在「发现」输入公开 GitHub 的 `owner/repository`（可指定 ref），或本地目录/ZIP 的绝对路径。也可以通过 skills.sh 搜索后发现仓库。
2. 查看 Skill 描述、仓库相对路径和 SKILL.md，选择应用与自动/符号链接/复制方式，预览并确认安装。不选择应用时只保存到 dbox 内容库。
3. 「已安装」支持名称/描述/来源/应用/状态筛选。批量操作只提交当前筛选中被选中的项目，并显示数量。
4. 单个应用可以启用/停用。Codex 和 Gemini 默认共同读取 `.agents/skills`，所以关联应用会一起操作。全部停用后内容库仍保留，可离线重新启用。
5. 「导入已有安装」按实际路径展示候选。导入先保存快照，原目录保持不变；只有「预览接管」确认后才替换外部部署。来源未知时保留 unknown，不猜测或写入其他管理器的 lock 文件。
6. 「只检查更新」不会改写安装内容或应用目录。GitHub 以原仓库、ref、完整相对路径匹配，安装固定到预览准备的 commit。来源未知、无法联网、远端路径消失、本地修改分别显示；可对当前筛选内有更新的项目批量更新。
7. 卸载先备份再移除托管部署和内容库。未接管的外部目录不会删除；有本地修改则保留记录，显示待清理。通过「备份恢复」生成恢复计划，不覆盖原操作之后的外部修改。

## MCP

- 通过「添加服务器」填写 stdio 的 command/args，或 HTTP/SSE 的 URL。env、headers、cwd 在配置 JSON 中编辑；应用专有字段在对应应用的高级字段中编辑。
- 配置 key 可以按应用分别设置。相同名称不会自动合并；同一应用 key 的占用会作为冲突显示。
- JSON 导入支持 `mcpServers` 对象或服务器映射；应用专有字段应通过「从应用配置导入」保留。导入只写 dbox 记录，不同步回应用文件。
- 列表展示期望启用与实际配置状态；启用、停用、删除、手动同步都会先显示脱敏文件预览。停用移除应用中的托管条目，定义仍保留在 dbox。
- 已有密钥在编辑器显示 `[REDACTED]`。可保留、设置新值或移除；保留会使用内部原值，占位符不会作为密钥落盘。普通列表、搜索、预览、事件和日志不包含真实 env/header/URL/参数值。
- Codex 支持 stdio/HTTP；SSE 会显示不支持。Gemini 的 allowed/excluded 阻止启用时会报告冲突。Claude 的项目级禁用/审批状态不在本版用户级管理范围中。
- 失败后重新读取列表。通过「重试此应用」只针对该目标重新预览同步，也可从备份恢复。

## 确认、记录与存储

预览不改写应用文件。确认绑定 10 分钟内有效的计划 ID/hash；来源、管理 JSON 或目标路径发生变化时需要重新预览。扩展操作串行执行，可取消后续步骤。多目标操作可以部分完成，运行记录会显示每个目标的结果和脱敏日志。

`AppPaths.config_dir` 下保存 `skills.json` / `mcp.json`；`data_dir/skills/<id>/content` 是不会被 Agent 自动加载的私有内容库；`extension-staging` 是临时准备内容；`extension-backups/<runId>/manifest.json` 与相关目录保存恢复数据。应用重启会清理暂存、标记未完成运行，不自动重放。

配置和备份文件在 Unix 使用 0600，私有目录为 0700。备份限制为 100 份 / 1 GiB，达到限制后需手动删除已完成或已恢复的旧备份；未收敛的失败操作备份不能删除。目录/文件替换不是跨进程事务，仍可能遇到不遵循锁协议的外部程序并发写入，因此保留备份和冲突检查。

在「应用路径与支持范围」中查看默认/环境/覆盖路径。已有绑定时不允许切换覆盖路径，避免把旧部署误认成新目标。自定义路径需要与应用实际配置一致。

## 当前限制

- 仅用户级；不包含项目级、私有 Git/任意 Git 主机、OAuth、MCP 连接测试/进程管理。
- 本地目录/ZIP 和来源未知的外部快照不能远程检查更新；可以显式重新导入。
- ZIP64、JSONC、Skill 内容中的嵌套符号链接及特殊文件会明确拒绝。外部安装的顶层链接可扫描、快照导入和显式接管。
- 单次归档最多 10,000 条目、单文件 16 MiB、展开后 128 MiB。预览缓存最多 64 份，发现缓存最多 256 个候选；重启后须重新发现/预览。
- 仅在 macOS 完成本轮编译、临时文件测试和浏览器验证；Windows 的符号链接权限与复制回退仍需实机验收。

## 隔离验证

可用不会扫描真实 Provider 或用户 Agent 目录的调试后端验证页面：

```sh
cargo run --manifest-path src-tauri/Cargo.toml --features dev-http --bin dev-http -- --fixture-root /tmp/dbox-ui-test
DBOX_DEV_HTTP_URL=http://127.0.0.1:15431 npm run dev -- --port 15432 --host 127.0.0.1
```

该模式仅存在于 debug/dev-http 构建，固定监听回环地址；所有管理记录、内容和 Agent 路径都位于指定 fixture 根目录。正式桌面启动和普通 `npm run dev:http` 仍使用原 `AppPaths`。
