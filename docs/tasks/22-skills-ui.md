# T22：Skill 管理界面

- 状态：Completed
- 阶段：扩展管理界面
- 依赖：T17、T21
- 阻塞：无

## 目标

替换现有 SkillsView 占位页，为 Rust 原生 Skill 服务提供完整桌面管理流程。以 [Skill 与 MCP 管理接入计划 P5](../skills-mcp-integration-plan.md#9-分阶段任务与验收) 为准，原来的 CLI 薄适配界面方案已替代。

## 交付内容

- “已安装 / 发现”视图；按名称、应用、来源和状态筛选，明确首版仅用户级支持。
- 已安装项展示描述、来源、期望启用状态、实际部署结果和更新状态。
- 仓库来源管理、skills.sh 搜索、从仓库/本地目录/ZIP 安装；来源结果结构化展示。
- 导入前展示真实来源路径与同名冲突；“导入快照”和“接管应用部署”分别说明影响。
- 按应用启停及批量操作；全部停用后仍显示库内 Skill，支持离线启用。
- 独立检查、单项/全部更新、卸载与备份恢复，使用后端计划及文件/部署预览。
- 复用确认、Run 日志和取消能力；成功/失败/部分成功后刷新权威列表，提供按失败目标重试。
- 不支持独立启停的共享目录、外部未接管项、来源未知、本地修改和不可用目标均明确显示。
- 使用 Vue/Pinia、现有组件和生成 DTO，同时支持 Tauri 和 dev HTTP transport。

## 测试要求

- mock DTO 覆盖空列表、搜索无结果、来源失败、冲突、停用保留、不可检查和 partial。
- 批量操作范围/数量与实际提交一致；pending 防止重复或冲突写入，过期响应不覆盖新状态。
- 前端不直接读写 Skill 文件，所有部署变化均通过原生后端计划。
- 取消、重新预览、恢复与失败后刷新都有组件/store 测试。

## 完成标准

用户能从界面完成 T21 的完整管理流程；操作结果与实际部署一致。CLI 可用与否不影响页面的基本使用，原工具管理界面不回退。

## 完成记录（2026-09-10）

SkillsView 已替换占位页；增加 Pinia store、来源/导入/备份入口、共享 OperationPanel 和应用路径面板。写入需预览确认，批量目标按当前筛选与选中项求交集，执行结束及事件重连后刷新权威状态。组件测试覆盖批量范围、显式接管、失败刷新、旧响应隔离；隔离浏览器流程验证本地发现→预览→安装→运行历史。
