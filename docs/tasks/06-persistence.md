# T06：设置、缓存与运行记录持久化

- 状态：Pending
- 阶段：Rust 核心
- 依赖：T01、T02
- 阻塞：T13、T14

## 目标

实现可测试、原子且不硬编码用户目录的本地持久化层。

## 交付内容

- 用 `AppPaths` 抽象 config/data/log 目录，生产环境由 Tauri path API 注入，测试使用临时目录。
- 读写 `settings.toml`、`state.json` 和按 Run 划分的 JSONL 日志。
- 写入采用同目录临时文件、flush/sync 与 rename，避免半写文件。
- 支持 schema version、默认值和迁移入口。
- 支持 revision/etag 乐观锁，防止覆盖外部修改。
- 实现日志数量/总大小轮转；正在运行的日志不得被删除。

## 单元测试

- 首次启动目录不存在时创建并返回默认设置。
- 写入后读取 round-trip；模拟中断时旧文件仍有效。
- revision 冲突返回错误，不静默覆盖。
- 损坏文件返回带路径错误，并保留原文件。
- 日志轮转遵守数量与大小，活动 Run 被保留。
- 测试只写临时目录，不写真实用户配置。

## 完成标准

持久化模块不依赖全局路径，可在临时目录重复运行；单元测试覆盖异常文件和原子写入行为。

## 非目标

- MVP 不引入 SQLite。
